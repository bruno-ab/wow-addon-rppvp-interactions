# BanterCombat — notas 17-9-2026

## Padrões do addon

- Namespace Lua: `local addonName, ns = ...`
- Load order no `.toc`: Data → Stats → UI.xml → UI.lua → core
- Mensagens addon: prefixo `BANTER_MSG`, payload separado por `\031`
- UI: fade com `UIFrameFadeIn` / `UIFrameFadeOut` (compat Classic)
- Retrato: `SetPortraitTexture` com fallback `CLASS_ICON_TCOORDS`
- Stats em `SavedVariablesPerCharacter` (`BanterCombatDB`), versionado

## Teste manual
