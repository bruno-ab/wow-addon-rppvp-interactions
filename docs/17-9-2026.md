# BanterCombat — 17-9-2026

## 1.2.0

### Bugs corrigidos
- Dedup prune: `now % 8` nunca disparava de forma confiável → contador a cada 32 inserts
- Encode: texto/badge truncados e sanitizados (pipe, controles, limite 180/48)
- Options: refresh dos checks/slider ao reabrir o painel; checkbox Debug
- UI: anim de entrada em Scale (sem conflito Fade+Translation); `generation` cancela hide atrasado; EdgeGlow com WHITE8X8 no Classic

### Features
- Filtros: `hostileOnly` (flags CLEU), `showDeaths`, `showGroupBanter` no receive
- `chatAnnounce` → espelha fala em EMOTE
- Early-out CLEU se `enabled == false`
- `PLAYER_ENTERING_WORLD` refresca GUID
- `/banter debug [on|off]`, `/banter history`, `/banter ignore` / `unignore`
- `/banter stats` com top 5 raças/classes

### Opções novas (defaults)
- `showGroupBanter = true`
- `showDeaths = true`
- `hostileOnly = true`
- `chatAnnounce = false`
- `debug = false`
