# BanterCombat — WoW Classic PvP Banter Addon

Addon de provocação PvP para **WoW Classic Era / Hardcore (1.15)** · versão **1.2.0**

## Instalação

Copie `BanterCombat/` → `World of Warcraft\_classic_era_\Interface\AddOns\` → `/reload`

## Comandos

| Comando | Efeito |
|--------|--------|
| `/banter test` | Pop-up de teste |
| `/banter revenge` | Vingança |
| `/banter milestone` | Conquista (50 Orcs) |
| `/banter stats` | Totais + top raças/classes |
| `/banter config` | Opções |
| `/banter queue` | Tamanho da fila |
| `/banter hide` | Esconde + limpa fila |
| `/banter debug [on\|off]` | Log de diagnóstico |
| `/banter history` | Últimas falas |
| `/banter ignore <nome>` | Ignora jogador (`list` / `clear`) |
| `/banter unignore <nome>` | Remove ignore |
| `/banter help` | Ajuda |
