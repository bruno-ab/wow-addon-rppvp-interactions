Custom announcer packs
======================

1. Create a folder next to this README, e.g. Sounds/MyPack/
2. Drop .ogg files using these exact names:

   FirstBlood.ogg
   DoubleKill.ogg
   TripleKill.ogg
   UltraKill.ogg
   Rampage.ogg
   KillingSpree.ogg
   Dominating.ogg
   MegaKill.ogg
   Unstoppable.ogg
   WickedSick.ogg
   MonsterKill.ogg
   Godlike.ogg
   HolyShit.ogg
   Ownage.ogg

3. In /banter config → Minhas falas / Lines, set Sound folder to the folder
   name only (example: MyPack). Missing files fall back to the built-in pack.

Built-in cues are Dota-style (Valve) plus Ownage (revenge / streak 6).
See Sounds/CREDITS.txt.
